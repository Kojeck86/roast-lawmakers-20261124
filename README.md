# The Long Roast: Lawmakers and the File They Cannot Convert

A make.fun entry for the bounty
[u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7):
one satirical sentence roasting the lawmakers who would write the rules
for artificial intelligence but cannot convert a file to PDF. The
committee drafting the AI law spends its morning asking an intern to
convert the draft, because the chairman printed it, signed it in pen,
and sent it back to be scanned in — authority first, undercut by the
file at the end.
